Starting your project
git init                  # turn your folder into a git repo
git remote add origin https://github.com/yourusername/your-repo.git  # connect to GitHub


git status                # see what files have changed
git add .                 # stage all your changes
git commit -m "your message here"   # save a snapshot
git push origin main      # send it up to GitHub


git log                   # see your commit history
git pull origin main      # pull down latest changes (useful later)

Here's everything you need for branching and merging:

Creating & switching branches
git branch                        # see all branches
git branch feature-nav            # create a new branch
git checkout feature-nav          # switch to it
git checkout -b feature-nav       # create AND switch in one command (shortcut)

Merging
git checkout main                 # switch back to main first
git merge feature-nav             # merge your branch into main
git branch -d feature-nav         # delete the branch after merging (cleanup)

Pushing a branch to GitHub
bashgit push origin feature-nav       # push a specific branch up
